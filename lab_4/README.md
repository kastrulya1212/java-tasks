## Основная информация
Челноков Д.Ю. Вариант 1. Группа ПИ-2-2

## Архитектура
Queue.java, QueueElement.java - файлы с классами
Sort.java - интерфейс, обозначает классы которые могут использовать сортировку
Task_1.java - точка входа, главный файл запуска

## Как запускать
Необходимо просто запустить главный файл Task_1.java
